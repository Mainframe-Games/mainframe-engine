# Plan

Write the plan before the code. Copy `.agents/mainframe-workflow/templates/plan.md` into the plans folder as `YYYY-MM-DD-slug.md`.

- Give it a status header.
- Cite the docs it relies on.
- Say how each step is verified.
- Make Done when checkable: a reader can tell yes or no without asking.

## While building

- Tick steps as they land.
- Never rewrite the list. Strike through a dropped step and give the reason.
- Only the status and the ticks change after the plan starts.
- Never delete a plan, including an abandoned one.
