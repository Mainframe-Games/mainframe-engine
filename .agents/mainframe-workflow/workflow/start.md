# Start

Do this before changing anything. Skip a step when `.agents/workflow.md` leaves its path blank.

1. Read `.agents/workflow.md`.
2. Read the state file.
3. Read the two or three newest logs, and the plans they reference.
4. Read the proposal or design doc for the area. Implement from it; do not re-derive it.
5. Check the branch, and whether the checkout is behind its remote. A stale checkout gives wrong answers.
6. Report in a few lines: where things stand, what comes next, and any conflict between docs and code.
7. Choose a size from the [table](README.md#size) and follow its path.
