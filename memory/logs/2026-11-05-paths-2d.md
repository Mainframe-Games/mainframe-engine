# 2026-11-05: 2D paths and the curve tool

Branch `feature/paths-2d`. Plan: [G13 2D paths and the curve tool](../plans/2026-11-05-paths-2d.md). Proposal:
[Paths](../../docs/design/future/paths.md); as built: [Paths](../../docs/design/paths.md).

## What changed

- **Engine:** `CurveBaker` (internal) now bakes both curves; `Curve2D` (Godot's API in pixels, `Closed`, tangents,
  `WrapOffset`, `SetSmoothPoints`, `Reverse`); `Curve3D.Reverse`; `Path2D` and `PathFollow2D` (Godot's names, `Speed`,
  `PingPong`, `ProcessCallback`, `Looped`, `EndReached`); `PathMotion`, the progress rules both followers share.
- **Editor:** `Path2D`s draw in 2D tabs; with one selected, the curve bar and `CurveEditor` edit its curve
  (`ICurveTarget`, `CurveEditing`, `SetCurvePointsAction`); Delete/Backspace remove the selected point; Add Node gives
  paths an inline curve (`NewNodeDefaults`); icons `vector-bezier`, `arrows-exchange`.
- **Demo:** `paths_2d` (cars lapping a track, a ping-pong lift, a guard on a patrol by the carrot recipe), its panel,
  Spanish strings, screenshot; the editor walkthrough draws and edits a path (`26e`–`26g`).
- **Docs:** paths, the proposal's status, milestones, editor, scene graph, demo, AGENTS.md, README and the landing page
  (feature, editor and Demo screenshots).

## Decisions

- [ADR 0242](../decisions/0242-path2d-and-the-curve-tool.md): one baker; the tool 2D-first on `ICurveTarget`, wired
  like the tile map editor until G8a.2 exists; undo actions never share the curve's live array.

## Dead ends

- None. One trap avoided: `Curve*.SetPointPosition` writes the point array in place, so an undo action holding the
  array the curve uses would be rewritten by the next drag. Gestures start the curve on a fresh copy, and the action
  applies copies (`CurveEditorTests.UndoAfterALaterDragRestoresTheEarlierState`).
