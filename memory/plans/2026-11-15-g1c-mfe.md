## Goal

`mfe anim rig|poses|bake|describe|check|list` runs the G1c tools from a terminal against a game project: Claude (or a
person) rigs a model, bakes or edits a clip from a script, reads it back and checks it, in readable text or one JSON
document (`--json`). `just mfe …` runs it in this repo.

## Not in scope

- `mfe anim render` (G1.17), editor reload (G1.18), the skill (G1.19).
- Folding `mf-l10n`/`mf-shaders` into `mfe` (owner: not now, ADR 0281).

## Design notes (decided here)

- `Tools/MainframeEngine.Cli/` (`AssemblyName` `mfe`, namespace `MainframeEngine.Cli`), like `mf-l10n`: `Program.cs` is
  `return MfeCli.RunConsole(args);`, `MfeCli.Run(args, output, error)` is testable, a hand-written `CommandLine`, unknown
  options are errors. In `MainframeEngine.slnx` under `/Tools/`.
- **Project:** `--project <dir>`, else the nearest `project.mfproj` walking up from the working directory. The run sets
  `ContentPaths.ProjectDirectory` and `AssetDatabase.Current` and restores both afterwards (tests run it in-process).
  Model, library and script content paths are project-relative; the script file itself is a path from the working
  directory (it lives in the session's scratch space). Gravity is the length of the project's `physics3D.gravity`.
- **Exit codes:** 0 ok; 1 checks found errors (a bake still writes its clip) or a command failed; 2 usage or input
  errors (bad script, missing file or clip, a refused replace): nothing written.
- **bake** takes a pose script or an edit script (`PoseScriptParser.IsEditScript`), writes it (`PoseLibrary.Write` /
  `WriteEdit`), prints tracks and key counts, notes and the checks (`AnimationCheckOptions.ForScript`; edits check with
  only the tolerances given). `--replace`, `--no-link`, `--tolerance`.
- **check** `--root inPlace|motion`, `--start <pose>`, `--end <pose>`, `--tolerance a=b,…`.
- **describe** `--times 0.2,0.4`. **rig** prints the bone tree, the map (source, confidence), unmapped and missing bones,
  rest kind and proportions; `--write-meta` stores the detected map in the `.mfmeta` `humanoid`.
- **JSON** through `Utf8JsonWriter` (indented), the same data as the text.

## Steps

- [x] Project, `CommandLine`, `MfeCli` (help, groups, errors, exit codes, project discovery). Verified by: CLI tests
  (help, unknown command/option, no project).
- [x] `anim rig`, `poses`, `list`. Verified by: CLI tests on a temp project with the test character (text and JSON,
  `--write-meta` writes the map once).
- [x] `anim bake` (pose and edit scripts), `describe`, `check`. Verified by: CLI tests (bake writes and links, checks run,
  exit 1 on errors, 2 on a bad script with the JSON path, `--replace` guard, edit script, describe text/JSON, check
  options and tolerances).
- [x] `just mfe`, solution entry, test project reference. Verified by: `just mfe anim poses` runs.
- [x] Docs (animation.md CLI section, proposal G1.16 built + changes, AGENTS.md), log. Verified by: `check.sh`,
  `just state-guard`.
- [x] Gates: `just build`, Release `-warnaserror`, `just test`, `just format-check`, `just shaders-check`, `check.sh`.

## Done when

- In a temp project with the test character, `mfe anim bake squat.json` writes the clip, links the library and exits 0;
  `describe`, `check` and `list` read it back; `--json` output parses.
- A script error exits 2 and names its JSON path; checks with errors exit 1.
- `just mfe anim poses` prints the bone list.
- The gates pass; a PR (stacked on #213) is open with Auto-fix on.
