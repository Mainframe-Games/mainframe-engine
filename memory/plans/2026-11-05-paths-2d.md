**Started:** 2026-11-05

## Goal

- **`CurveBaker`** (internal): the adaptive subdivision and equal-arc resampling move out of `Curve3D` and are shared
  with `Curve2D`. `Curve3D`'s committed bake hash is unchanged.
- **`Curve2D`** (pixels): Godot's API (`AddPoint`, `Get/SetPointPosition/In/Out`, `RemovePoint`, `ClearPoints`, `Sample`,
  `SampleBaked`, `SampleBakedWithRotation` → `Transform2D`, `GetBakedLength`, `GetBakedPoints`, `GetClosestOffset`,
  `GetClosestPoint`) plus `Closed`, `SegmentCount`, `SampleBakedTangent`, `WrapOffset`, `SetSmoothPoints` and `Reverse`.
  6 floats per point, `BakeInterval` 5 px. `Curve3D` gets `Reverse` too.
- **`Path2D`** and **`PathFollow2D`**: Godot's names and defaults (`Progress`, `ProgressRatio`, `HOffset`, `VOffset`,
  `Rotates`, `CubicInterp`, `Loop`) and the 3D slice's extensions (`Speed`, `PingPong`, `ProcessCallback`, `Looped`,
  `EndReached`). +X along the tangent. No allocation per frame.
- **The editor draws** every `Path2D` in a 2D tab (debug colour, selection colour when selected).
- **The curve tool in 2D tabs:** with one `Path2D` selected, a curve bar over the view (Select, Add, Insert, Delete,
  Close, Reverse, Smooth) and point and tangent handles: drag points and tangents (mirrored unless Shift), Ctrl/Cmd+click
  adds, a click on a segment inserts there without changing the shape (de Casteljau), Delete removes, grid snap when
  Snap is on, Esc or a right click cancels a drag. Every gesture is one undo step on the curve's `Points`. A new
  `Path2D` from Add Node gets an inline `Curve2D`. The tool's core works on an `ICurveTarget` in 3D coordinates (2D:
  z = 0) so G13.6 adds a `Path3D` adapter rather than a second tool.
- **Demo:** a `paths_2d` scene in the 2D category: a closed track with followers at different speeds and rotations, a
  ping-pong platform, and a guard walking a patrol by the carrot recipe. `Demo.Tests` checks a follower completes a lap.

## Not in scope

- G13.5 moving platforms (`AnimatableBody*`, platform velocity): the demo's platform is a plain sprite on a follower.
- G13.6 the 3D curve tool (tilt ring, ground snap, `CurveTerrainFit`), and `River3DTool`.
- The closest-point grid and the hinted closest query (not in the 3D slice either; linear scan as today).
- Forest rails on `Path3D` (G13.8).

## Design notes (decided here)

- **Baker input.** `CurveBaker` bakes from a reused scratch array of segment controls (p0, c0, c1, p1 per segment,
  `Vector3`), which each resource fills (2D with z = 0). Same arithmetic in the same order, so the 3D hash holds and 2D is
  bit-exact too. It owns the dense polyline and the baked points, distances, params (segment + t) and tangents; `Curve3D`
  keeps its tilt, width, depth and up vectors, computed from the baked params as today.
- **Shared follower logic.** `PathProgress` (internal struct): constrain, advance with loop, clamp and ping-pong, and
  the two events, used by `PathFollow3D` and `PathFollow2D`. `PathFollow3D` behaviour and tests unchanged.
- **Tool shape.** `CurveEditor` is owned by the workspace and wired like `TileMapEditor` (press, move, release, cancel,
  draw, commands, a bar in the viewport panel), not as a G8a.2 `IEditorViewportTool`, which is still unbuilt. When G8a.2
  lands, `CurveEditor` becomes one implementation of it.
- **Undo.** A gesture captures `Points` before, applies live, and commits one `SetPropertyAction` on `Curve2D.Points`
  with `alreadyApplied: true` (`Closed` changes go through the same action type on `Closed`).
- **Icons.** `Path2D` `route-2`, `PathFollow2D` `map-pin` (the 2D family colour), `Curve2D` `vector-bezier` (vendored with
  `just editor-icons-fetch`).
- **Proposal open question 2** (keep the follower extensions): already kept by ADR 0215; 2D matches.

## Steps

- [x] **`CurveBaker`.** Extract from `Curve3D`; add `Curve3D.Reverse`. Verified by: `Curve3DTests.FixedCurveBakesToACommittedHash`
  and every `PathCurveTests`/water test unchanged and green; `Reverse` twice is the identity.
- [x] **`Curve2D`.** The resource on `CurveBaker`. Verified by: `Curve2DTests` (Godot API, closed square length, tangent
  continuity across the seam, `SampleBakedWithRotation` +X along the tangent, smooth points pass through every point,
  `Reverse`, closest point, serialization round trip, a committed bake hash, 0 B for sampling and queries).
- [x] **`Path2D`, `PathFollow2D`, `PathProgress`.** Verified by: `PathFollow2DTests` (placement, `Rotates`, offsets, loop,
  clamp, ping-pong with one signal per event, ratio round trip, curve change re-places, `Speed` on the chosen callback,
  not-a-child warning, serialization, 0 B with 16 followers) and `PathFollow3DTests` unchanged.
- [x] **Editor drawing and creation.** Paths draw in 2D tabs; Add Node gives a `Path2D` an inline `Curve2D`; icons.
  Verified by: an editor test that a new `Path2D` has a curve, and `just editor` on the Demo's paths scene.

- [x] **Demo `paths_2d`.** Scene, written `.mscene`, `Demo.Tests` lap check, screenshot. Verified by: `Demo.Tests` green and
  `just demo-screenshots` PNG inspected.
- [x] **Docs.** `paths.md` (2D, curve tool), the proposal's status, `milestones.md` G13 row, `editor.md` (curve tool),
