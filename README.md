# Mainframe Engine
Mainframe Engine is a collection of repositories for making games using [Spine](https://en.esotericsoftware.com/) in C#.

# Proposal
- Rendering: https://github.com/dotnet/Silk.NET
- Spine: https://github.com/EsotericSoftware/spine-runtimes
- Audio: https://github.com/sunkin351/FmodAudio
- ImGui: https://github.com/ImGuiNET/ImGui.NET
- UI: https://github.com/wjakob/nanogui
- Physics:
  - Jolt: https://github.com/amerkoleci/JoltPhysicsSharp
  - Box2D: https://github.com/codingben/box2d-netstandard
- Steamworks: https://github.com/rlabrecque/Steamworks.NET
- Networking: https://github.com/nxrighthere/ENet-CSharp
